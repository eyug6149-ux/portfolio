# Eyasu Guta — Personal Portfolio

A responsive static portfolio for Eyasu Guta, a computer science and engineering graduate and full-stack web development student.

## Main Features

- Responsive navigation and mobile menu
- About, education, skills, academic projects, services, and contact sections
- Project details dialog
- LinkedIn and GitHub profile links
- CV download
- Email application contact form
- Accessible keyboard navigation and reduced-motion support

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

Open a terminal in the project folder and run:

```powershell
python -m http.server 4173
```

Visit `http://127.0.0.1:4173/`.

## Deploy with GitHub Pages

1. Push the project files to the repository's `main` branch.
2. Open the repository on GitHub.
3. Go to **Settings** > **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and the `/ (root)` folder, then save.
